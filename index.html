Ganti password default agar hanya kamu yang bisa mengakses dashboard. Setelah mengganti password, pastikan melakukan ekspor ulang file index.html untuk GitHub Pages.

Publikasikan Perubahan ke GitHub Pages

Setiap perubahan otomatis tersimpan di browser ini. Untuk memperbarui halaman publik di GitHub Pages agar bisa dilihat semua orang:

  1. Klik tombol "Salin Kode HTML Siap Deploy" atau "Download File index.html" di bawah ini.
  2. Buka repository GitHub kamu, lalu timpa / edit file index.html.
  3. Klik Commit changes dan tunggu GitHub Pages selesai memperbarui situs.
